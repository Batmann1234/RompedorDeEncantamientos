# RompedorEncantamientos

Menú `/rompedor` (alias `/romper`): pones un ítem de MythicMobs en el slot central, se destruye,
recibes su versión limpia y todas sus runas de AdvancedEnchantments al 100%.

Requisitos: Paper/Purpur 1.21.x, Java 21, MythicMobs y AdvancedEnchantments.

Compilar: sube el repo a GitHub; en la pestaña **Actions** descarga el artefacto `RompedorEncantamientos`.
Local: `mvn clean package` (el jar queda en `target/`).
